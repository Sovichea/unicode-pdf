# Manual PDF copy/paste release checklist

Use this checklist for reader UI behavior that is not exposed through a stable automated clipboard API.

For every fixture PDF generated by `scripts/run-conformance.sh`:

1. Open the PDF in the reader under test.
2. Verify that the visible text has the expected shaping and direction.
3. Select the complete fixture text using the reader's normal selection UI.
4. Copy it.
5. Paste into a plain UTF-8 text editor with no rich-text transformation.
6. Save the pasted text as UTF-8.
7. Compare it to the corresponding file in `fixtures/` by Unicode scalar sequence.
8. Record the reader name, exact version, operating system, `PASS`/`FAIL`, and attach the pasted UTF-8 text on failure.

Minimum release matrix:

| Reader | Platform | Khmer | Devanagari | Arabic | Mixed BiDi |
|---|---|---|---|---|---|
| Adobe Acrobat/Reader | Windows | | | | |
| Adobe Acrobat/Reader | macOS | | | | |
| Chrome PDF viewer / PDFium | Windows or Linux | | | | |
| Edge PDF viewer / PDFium | Windows | | | | |
| Firefox PDF viewer / PDF.js | Windows or Linux | | | | |
| Preview | macOS | | | | |
| iOS system PDF viewer | iOS | | | | |
| Android system/Chrome PDF viewer | Android | | | | |

A release result is only called “copy/paste exact” when the pasted Unicode itself matches. Visual correctness alone is insufficient.

## Compare a saved paste

After saving the pasted clipboard text, run:

```bash
python3 conformance/compare_copy.py fixtures/khmer.txt pasted-khmer.txt
```

The command exits with status 0 only when the selection-equivalent Unicode matches. On failure it prints the first differing scalar with Unicode names and nearby code points.
